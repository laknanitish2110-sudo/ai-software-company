# LaunchpadX Hackathon

2-day national hackathon at **SNIST, Hyderabad** — Aug 22-23, 2026.

## Theme

> [!decision] Agentic AI, GenAI & Agent Building
> Build solutions using agentic AI according to problem statements. This is not "use ChatGPT to solve a problem" — it's "build an agent system that demonstrates how AI agents collaborate."

## Why We're a Perfect Fit

Our project IS the theme:

| What they want | What we have |
|----------------|-------------|
| Agentic AI | 6 autonomous agents with specialized roles |
| Agent collaboration | Cross-review system — agents review each other |
| Human-in-the-loop | 4 approval gates — founder steers every decision |
| Tool use | Tavily search, file generation, PPTX creation |
| Orchestration | Pipeline engine with state management |
| Real output | Working deployed apps, not just text |

## Demo Strategy

> [!pipeline] The 5-Minute Pitch
> 1. Open with the hook: "What if 6 AI agents could build your entire project?"
> 2. Paste a problem statement live
> 3. Show agents working in real-time (streaming + Agent Canvas)
> 4. Show the live deployed URL (Level 4 Engineer)
> 5. Show deliverables: working app + PPTX + DOCX
> 6. Show agent architecture visualization
> 7. Drop the cost: "$0.26 per complete project"

## Key Differentiators

> [!agent] What Makes Us Different from ChatGPT
> 1. **6 agents, not 1** — each thinks differently about the same problem
> 2. **Real deployed apps** — click a link, see it working
> 3. **Approval gates** — same input, different feedback = unique output
> 4. **Cross-review** — agents review each other's work
> 5. **Transparent architecture** — judges can inspect every agent's decision
